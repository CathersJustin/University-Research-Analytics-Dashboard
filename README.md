# University Research Analytics Dashboard

## Overview

This project simulates an end-to-end Business Intelligence solution for a university Office of Research.

The project demonstrates how Python, SQL, and Tableau can be combined to transform research proposal and award data into interactive executive dashboards that support strategic decision-making.

---

## Objectives

- Analyze research proposal activity
- Measure proposal success rates
- Track awarded funding
- Compare colleges and departments
- Evaluate funding agencies
- Produce executive dashboards
- Document the complete analytics workflow
